# FuseMoE Migraine Prediction System - Final Package

This package contains the code, documentation, and configuration for the FuseMoE-based migraine prediction system.

## Contents:

*   **`/` (Root Directory):**
    *   `README.md`: This file.
    *   `data_processor.py`: Script for loading, preprocessing, and structuring data from synthetic generators (or potentially MIMIC-IV/Synthea).
    *   `updated_fusemoe_integration.py`: Contains the `FuseMoEMigraineModel` definition, the `FuseMoEAdapter` class, and helper functions, incorporating fixes for FuseMoE library compatibility.
    *   `train_evaluate.py`: Script to train the `FuseMoEMigraineModel`, evaluate its performance, and save results to `evaluation_results.json`.
    *   `dashboard.py`: Streamlit application to visualize model performance metrics loaded from `evaluation_results.json`.
    *   `implementation_documentation.md`: Detailed documentation of the system's implementation.
    *   `evaluation_results.json`: (Generated by `train_evaluate.py`) Contains the performance metrics (Accuracy, Precision, Recall, F1, ROC AUC) from the model evaluation.
    *   `synthetic_data_generator.py`: Main script to generate synthetic patient and migraine data.
    *   `patient_profile_generator.py`: Generates synthetic patient profiles.
    *   `sleep_data_generator.py`: Generates synthetic sleep data.
    *   `weather_data_generator.py`: Generates synthetic weather data.
    *   `stress_diet_generator.py`: Generates synthetic stress and diet data.
    *   `migraine_event_generator.py`: Generates synthetic migraine events.
    *   `correlation_engine.py`: Dependency for synthetic data generation.
    *   `data_export_module.py`: Dependency for synthetic data generation.
*   **`/FuseMoE/`:** Contains the modified FuseMoE library code.
    *   `src/core/hme_seq.py`: Modified Hierarchical MoE implementation.
    *   `src/core/sparse_moe.py`: Modified Sparse MoE implementation.
    *   `src/utils/config.py`: Original FuseMoE configuration class (required).
    *   `src/core/model.py`: Original FuseMoE base model class (potentially required).
*   **`/data/`:** (Generated by `synthetic_data_generator.py`) Contains the raw synthetic CSV data files.

## Usage Instructions:

1.  **Environment Setup:** Ensure you have Python 3.10+ and required libraries installed (PyTorch, Pandas, NumPy, Scikit-learn, Streamlit). You might need to install them using pip:
    ```bash
    pip install torch pandas numpy scikit-learn streamlit
    ```
2.  **Generate Synthetic Data (Optional):** If you don't have data, run the generator:
    ```bash
    python3 /path/to/package/synthetic_data_generator.py 
    ```
    This will create CSV files in the `/path/to/package/data/` directory.
3.  **Train and Evaluate Model:** Run the training script:
    ```bash
    python3 /path/to/package/train_evaluate.py
    ```
    This will process the data in `/data/`, train the FuseMoE model, evaluate it, and save the results to `/path/to/package/evaluation_results.json`.
4.  **View Dashboard:** Launch the Streamlit dashboard:
    ```bash
    streamlit run /path/to/package/dashboard.py
    ```
    Access the URL provided in the terminal in your web browser.

## Important Note on Dependencies:

This code was developed and tested in an environment where dependency conflicts arose, particularly between NumPy version 2.x and older versions of SciPy and scikit-learn, preventing the `train_evaluate.py` script from running successfully in the final stages.

**Issues Encountered:**
*   **NumPy 2.x vs SciPy/scikit-learn:** Running `train_evaluate.py` may result in errors like `ImportError: numpy.core.multiarray failed to import` or `AttributeError: _ARRAY_API not found`. This is due to binary incompatibilities between NumPy 2.x and the versions of SciPy/scikit-learn used.
*   **Protobuf vs TensorBoard/PyTorch:** If using TensorBoard (currently commented out in `train_evaluate.py`), you might encounter `TypeError: Descriptors cannot be created directly.` This requires downgrading `protobuf` (e.g., `pip install protobuf==3.20.3`).

**Recommendations for Setup:**
*   **Use a Virtual Environment:** It is highly recommended to create a dedicated virtual environment (using `venv` or `conda`) to manage dependencies and avoid system-wide conflicts.
*   **Install Compatible Versions:** To run `train_evaluate.py`, you will likely need to install specific, compatible versions of the libraries. A potential starting point could be:
    ```bash
    pip install torch pandas "numpy<2.0" scikit-learn scipy streamlit protobuf==3.20.3 
    ```
    You may need to adjust versions further based on your specific environment and any remaining errors.
*   **Mock Results:** Due to these issues, the included `evaluation_results.json` contains mock data to allow the dashboard to function.

## Original Notes:

*   The `physio_expert` currently uses placeholder data. Integrating real physiological signals is a key area for future work.
*   Model hyperparameters in `train_evaluate.py` and `updated_fusemoe_integration.py` can be tuned for better performance.
